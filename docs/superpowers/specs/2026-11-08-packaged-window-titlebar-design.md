# Упакованный экран и управление окном

## Намерение

Починить пустое окно установленной Windows-сборки и убрать системное меню File/Edit/View/Window, заменив его управлением в существующей тёмной шапке приложения.

## Подтверждённая причина

Vite по умолчанию выпустил абсолютные ссылки `/assets/...`. Electron открывает `dist/index.html` через `file://`, где эти ссылки ведут в корень диска, поэтому JS и CSS не загружаются. Меню и белая рамка создаются стандартным окном Electron, вне React-интерфейса.

## Подходы

- Скрыть только меню: быстро, но белая системная рамка останется.
- Безрамочное окно и кнопки в React-шапке: все элементы управления выглядят как часть Music Train; требуется ограниченный preload мост для действий окна. **Выбран этот вариант**, потому что он совпадает с просьбой пользователя.

## Границы

- Перевести Vite build на относительные asset-пути для `file://`.
- Использовать безрамочное Electron окно; меню по умолчанию отключить.
- Добавить в имеющуюся шапку свернуть/развернуть/закрыть, сохранив drag-зону.
- Подключить preload и открыть только конкретные IPC действия окна; не раскрывать общий IPC.
- Собирать Windows x64 установщик в отдельный локальный каталог; не менять опубликованные версии.

## Проверка

- `npm run build` должен завершиться и выпустить `dist/index.html` со ссылками `./assets/...`.
- Упакованный `app.asar` должен содержать новый интерфейс и корректные относительные пути.
- Получить обновлённый Windows installer. Запуск установщика или приложения не входит в сборку.
