# Beta: такт и горячие клавиши

## Intent

Сделать метроном полезным не только для треков в 4/4 и ускорить управление повтором во время игры на инструменте.

## Goals

- Выбирать размер 3/4 или 4/4 отдельно для каждого видео; новый и старый профиль по умолчанию остаётся 4/4.
- Подсвечивать первую долю каждого такта согласно выбранному размеру.
- Управлять готовым видео с клавиатуры: Space — play/pause, ←/→ — ±5 секунд, A/B — поставить границы, M — включить/выключить метроном, ? — показать подсказку.
- Не перехватывать клавиши, когда пользователь вводит ссылку или двигает ползунок; короткие переходы не выходят за границы видео.
- Сохранять размер в локальных настройках видео; не сохранять состояние включённого метронома между запусками.

## Non-goals

- Автоматически определять размер, темп или доли.
- Добавлять MIDI, табулатуры, облачную библиотеку или загрузку аудио.
- Менять текущий Electron/React стек или добавлять зависимости.

## Constraints

- Использовать официальный YouTube IFrame Player API; приложение хранит только настройки тренировки.
- Сохранять прежние профили без миграции вручную: отсутствующий или неверный размер становится 4/4.
- Управления, требующие видео, работают только после готовности плеера.
- Существующие ограничения A/B и ручной BPM остаются неизменными.

## Approaches

1. **Компактное расширение текущей сессии (выбрано).** Добавить размер в `PracticeSettings`, одну чистую функцию акцента и один обработчик клавиш в текущем экране. Это сохраняет per-video storage и минимизирует риск рассинхрона плеера.
2. **Большая библиотека с маркерами и несколькими петлями.** Полезно позже, но требует отдельного формата данных и перестройки интерфейса; не решает ошибочный акцент в 3/4.
3. **Автоопределение ритма/размера.** Сложно проверить и отдельно названо следующим этапом; для беты оставляем размер ручным.

## Design

Размер — поле `timeSignature: 3 | 4`, с default `4`, включённое в существующие sanitize/load/save функции. Чистая функция `isDownbeat(beatIndex, beatsPerBar)` определяет акцент; планировщик использует её при создании щелчка. В карточке метронома разместить компактный доступный переключатель 3/4 · 4/4 рядом с темпом.

Глобальные клавиши подключить к окну приложения только для клавиш вне `input`, `textarea`, `select`, `contenteditable` и диапазонных ползунков. Клавиши управления проигрыванием игнорируются до `playerReady`; `?` открывает доступную компактную справку, а Escape закрывает её. Короткая перемотка всегда ограничивается диапазоном `0..duration`.

## Acceptance

- 3/4 акцентирует beat indexes 0, 3, 6; 4/4 — 0, 4, 8.
- Выбор размера восстанавливается для видео независимо от другого видео; старые данные дают 4/4.
- Горячие клавиши выполняют указанные действия только при готовом плеере и не срабатывают в полях ввода.
- Стрелки не выводят текущую позицию за начало или конец видео.
- Все тесты, production build и GitHub CI зелёные; визуальное ревью бета-панели пройдено.
