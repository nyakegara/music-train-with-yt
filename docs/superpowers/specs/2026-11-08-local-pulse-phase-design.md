# Локальная оценка начала пульса — дизайн

## Намерение

Показать ориентир для начала устойчивого пульса по выбранному пользователем локальному аудио, чтобы ускорить настройку метронома. Анализ остаётся на компьютере; приложение не скачивает звук из YouTube и не отправляет его стороннему сервису.

## Подходы

1. **Тихо записывать оценку как первую долю (отклонён).** Просто, но первый слышимый удар может быть второй или третьей долей такта, а аудиофайл может начинаться иначе, чем видео. Это незаметно сместит акцент метронома.
2. **Показать найденное начало пульса как подсказку с явным применением (выбран).** Анализатор оценивает фазу регулярных атак, показывает время и уверенность; пользователь сам переносит её в текущую метку метронома и проверяет совпадение с роликом. Чуть больше действий, зато сомнительный результат не меняет настройку незаметно.
3. **Оставить первую долю полностью ручной (отклонён).** Точнее при любой музыке, но не помогает быстрее найти исходную точку ритма.

## Цели и ограничения

- Переиспользовать локальные PCM-сэмплы и темп, вычисленные текущим анализатором BPM.
- Независимо оценивать качество фазы: высокая уверенность BPM сама по себе не означает надёжную временную метку.
- Вернуть начало наиболее уверенного устойчивого участка: первый импульс должен совпасть с фазой и иметь два следующих последовательных попадания; иначе вернуть `null`.
- Никогда автоматически не менять сохранённую `firstBeat`; предложенная метка применяется только после нажатия пользователя и только для того же видео, для которого начат анализ.
- Объяснить, что это начало устойчивого пульса, а не гарантированно первый слышимый импульс или музыкальная первая доля такта. Совпадение записи с YouTube пользователь проверяет на слух; существующая точная ручная настройка остаётся доступна.
- При слабой/синкопированной фазе оставить прежние настройки без изменения и сообщить, что уверенной метки нет.
- Если время найденного импульса позже длительности видео, отключить применение и объяснить, что нужно выбрать совпадающую версию записи.

## Не входит

- Автоматическое распознавание downbeat, размера такта или акцентов.
- Скачивание аудио с YouTube, передача файла наружу или длительное хранение аудиоданных.
- Автоматическая синхронизация локального аудио с YouTube по waveform.

## Детали реализации

- Расширить результат `estimateBpm` необязательной оценкой `firstPulseSeconds` и независимой `phaseConfidence`, сохранив текущий BPM-контракт для потребителей.
- Найти фазу по повторяемой onset-энергии относительно уточнённого периода автокорреляции (`chosen.lag + offset`), а не по округлённому BPM, чтобы не накапливать дрейф. Просмотреть все локальные окна и вернуть наиболее уверенный кандидат, чтобы неоднозначное вступление не блокировало чистый основной ритм.
- Не проецировать сетку назад через вступительную тишину: выбрать первый достаточно сильный onset, поддержанный фазой и двумя соседними ударами. Использовать низкий порог, чтобы тихое вступление (контраст примерно 1:100) не отбрасывалось из-за громкой поздней части; достаточную опору проверять фазой и повторяемостью.
- В UI выводить кандидат в секундах и отдельную кнопку «Применить начало пульса». По нажатию обновлять `firstBeat` только после проверки активного `videoId`; кандидат позже длительности ролика нельзя применить.
- BPM может примениться по существующим правилам. Отдельный кандидат фазы не должен зависеть от выбора half/double BPM, если состояние устарело.

## Проверки

- Импульсы с нулевого старта, со сдвигом, после тишины и с пропущенными начальными долями должны возвращать время первого устойчивого импульса.
- Нецелый BPM на длинном сигнале и небольшая временная вариация не должны давать заметный фазовый дрейф.
- Тихий импульс на вступлении (контраст 1:100), неоднозначное вступление перед чистым ритмом, ранний одиночный transient, три поздних удара, слабый/шумный звук и невалидные данные проверяют устойчивость фазовой уверенности.
- UI не меняет `firstBeat` после одного анализа, даёт применить кандидат явно, не применяет его после переключения видео или за концом ролика, сохраняет ручное значение при отказе и при смене BPM.
- Все исходные ограничения локального анализа файла сохраняются.
