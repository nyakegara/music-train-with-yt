# План: упакованный экран и управление окном

1. Поменять Vite base на относительный путь для `file://` сборки.
2. Указать preload в BrowserWindow и безопасные IPC методы свернуть/развернуть/закрыть.
3. Убрать меню Electron и включить frameless BrowserWindow.
4. Добавить кнопки окна в текущую верхнюю шапку и оформить drag/no-drag зоны.
5. Выпустить production renderer и NSIS x64 установщик в отдельную папку.
6. Проверить asset-ссылки в `dist/index.html`, наличие UI и preload в `app.asar`, метаданные установщика.
